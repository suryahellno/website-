02 // Defining the Structural Paradigm

struct Student {
    int id;
    char name[50];
    float gpa;
};

Builder Command

Initiates the blueprint using the struct keyword.

Members

The internal data architecture. Variables declared inside.

Mandatory Termination

The semicolon ; signals the end of the structure definition.

CRITICAL DIAGNOSTIC: Defining a structure allocates 0 Bytes of memory. It simply creates the architectural blueprint.

05 // The Alignment Protocol: Structure Padding

struct Diagnostic {
    char a; // 1 byte
    int b;  // 4 bytes
};
1 + 4 = 5 Bytes
Actual Size: 8 Bytes
Padding Bytes Added
char a
///
int b (4 bytes)
The compiler injects empty padding bytes to align data on memory boundaries. This sacrifices minimal space to achieve vastly faster CPU read cycles.

06 // Memory Optimisation & Packing

Optimised Ordering

Order structure members from largest byte size to smallest to naturally minimise compiler padding.

long (8)
int (4)
short (2)
char (1)
Total Size: 15 Bytes (No Padding)

Structure Packing Directives

#pragma pack(1)
struct PackedDiagnostic {
    char a; int b;
};
char a
int b
Packed Size: 5 Bytes (Padding Removed)

Trade-off Diagnostic

Forcing packed memory saves space but incurs CPU performance penalties during read operations. Use cautiously.

08 // Scaling Internal Complexity: Nested Structures

struct Date {
    int day;
    int month;
    int year;
};

struct Person {
    char name[50];
    struct Date birthdate; // Nested Structure
};

person1.birthdate.year = 1998;

Structures can seamlessly encapsulate other structures, allowing for deeply nested data architectures accessed by chaining the dot operators.
